# Travaux Pratiques C# — Master Technologie Immersive

Ce repository est destiné au dépôt des travaux pratiques de C# des étudiants du Master Technologie Immersive.

## Organisation des travaux

Chaque étudiant doit déposer ses réponses dans un dossier portant son nom.

Exemple :
- TP01/Nom_Prenom/
- TP02/Nom_Prenom/
- TP03/Nom_Prenom/

Chaque dossier doit contenir les fichiers du projet C# et les réponses demandées.

**Enseignant :** Les travaux sont accessibles dans ce repository pour consultation et évaluation.
