# Travaux Pratiques C# — Master Technologie Immersive

Ce repository est destiné à l'organisation et à la consultation des travaux pratiques de C# réalisés par les étudiants du **Master Technologie Immersive**.

## Organisation des travaux

Chaque étudiant dispose de son propre repository pour déposer ses travaux pratiques.

Les repositories sont organisés selon les travaux réalisés (TP01, TP02, TP03, etc.).

Chaque repository contient les fichiers du projet C#, le code source et les réponses aux exercices demandés.

## Consignes aux étudiants

1. Déposer les fichiers du projet C# dans votre repository.
2. Organiser les fichiers de manière claire et structurée.
3. Vérifier que les dernières modifications ont été enregistrées avec un commit et envoyées sur GitHub.
4. Conserver les fichiers nécessaires à l'exécution et à l'évaluation du projet.

## Consultation par l'enseignant

L'enseignant peut accéder directement aux travaux de chaque étudiant à partir des liens ci-dessus pour consulter le code source, suivre les modifications et évaluer les réalisations.
